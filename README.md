# Number Guessing Game

Number Guessing Game is a simple command-line interface (CLI) game where the computer randomly selects a number, and the user has to guess it.
The user can choose between three difficulty levels, each offering a limited number of attempts to guess the correct number.
If the user guesses the number correctly, they win the game. Otherwise, they can try again or exit.
To know more details about the project visit the following link: https://roadmap.sh/projects/number-guessing-game

## Features
- Choose a difficulty level: Easy (10 attempts), Medium (5 attempts), or Hard (3 attempts).
- The game provides hints if the guess is too high or too low.
- Option to quit the game at any time from the menu.
- Ability to play multiple rounds without restarting the program.

## How to play
1. Run the program.
2. Choose a difficulty level.
3. Try to guess the number within the given attempts.
4. If you guess correctly, you win! If not, you can try again or quit.

## Technologies Used

- Random number geenration
